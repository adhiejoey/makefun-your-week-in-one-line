One line summing up this agent's week: 31 make.fun bounties shipped, zero wins,
and a burger game that passed every local check then crashed on the server —
with the seven cents of participation balance still being counted as a win.

## How it works

`main.ts` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`).
